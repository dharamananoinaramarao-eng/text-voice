C Programming Operators

Learn how operators are used in C

1. What is an Operator?

An operator is a symbol that tells C to perform an operation on one or more values. 

int a = 10;
int b = 5;

int result = a + b;

Here, + is the operator.

2. Arithmetic Operators

Arithmetic operators are used for mathematical calculations.

Operator Name Example
+ Addition 10 + 5
- Subtraction 10 - 5
* Multiplication 10 * 5
/ Division 10 / 5
% Remainder 10 % 3

Example

#include <stdio.h>

int main() {

    int a = 10;
    int b = 3;

    printf("Addition = %d\n", a + b);
    printf("Subtraction = %d\n", a - b);
    printf("Multiplication = %d\n", a * b);
    printf("Division = %d\n", a / b);
    printf("Remainder = %d\n", a % b);

    return 0;
}

Output

Addition = 13
Subtraction = 7
Multiplication = 30
Division = 3
Remainder = 1

3. Relational Operators

Relational operators compare two values. They return 1 for true and 0 for false.

Operator Meaning
== Equal to
!= Not equal to
> Greater than
< Less than
>= Greater than or equal
<= Less than or equal

Example

int a = 10;
int b = 5;

printf("%d", a > b);

Output

1

4. Logical Operators

Logical operators are used to combine conditions.

Operator Meaning
&& AND
|| OR
! NOT

Example

int age = 20;

if (age >= 18 && age <= 60) {

    printf("Eligible");

}

5. Assignment Operators

Assignment operators are used to assign or update values.

Operator Example Meaning
= a = 10 Assign
+= a += 5 a = a + 5
-= a -= 5 a = a - 5
*= a *= 5 a = a * 5
/= a /= 5 a = a / 5

6. Increment and Decrement

++ increases a value by 1.

-- decreases a value by 1. 

int a = 10;

a++;

printf("%d", a);

Output

11

7. Conditional Operator

The conditional operator is also called the ternary operator.

It uses: 

condition ? value_if_true : value_if_false;

Example

int age = 20;

char *result =
    (age >= 18) ? "Adult" : "Minor";

printf("%s", result);

Output

Adult
